# Security Policy

The **iStore Customer Portal** team values the security and privacy of our users.

---

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT open a public GitHub issue. 
Disclose vulnerabilities responsibly through [GitHub Security Advisories](https://github.com/SahanPramuditha-Dev/I-Store-Customer-Portal/security/advisories/new) or by reaching out to the project maintainers.
